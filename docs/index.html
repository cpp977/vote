Information We Collect

1. Information you provide directly

E-Mail address.

2. Information collected automatically

We may collect certain information automatically when you access or use the App, including device information (model, OS version), and IP addresses.

3. Voting decisions

We do not safe at all which user voted for which answer. For each answer, we only store anonymous tags (birth year, gender, country, ...) and not your ID. Even with full access to the underlying database it is theoretically impossible to find which answers are given by a specific user. The only thing we save is that you voted for a given question. We do this securely by storing a hash value of user ids together with questions a user voted.

How We Use Your Information

  • We store the information of which questions are voted by a user to ensure that users can only vote once per question;
